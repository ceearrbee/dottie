Dottie

A cosy Matrix chat client.

About

Dottie is a personal, open-source fork of Element X Android — a secure Matrix messenger. It talks to whichever homeserver you sign in to; it isn't a service run by anyone, just an app you install.

Source code lives at github.com/ceearrbee/dottie.
